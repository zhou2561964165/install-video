### 4. 计算机的基本功能

讲者从高层回答“计算机到底做什么”：

- 根本上，计算机做两件事：
  1. **执行计算**：计算量很大。讲者说现在的计算机速度非常快，每秒十亿次计算可能并不算离谱。
  2. **存储计算结果**：存在计算机内存中。今天拥有数百 GB 存储的计算机并不罕见。
- 计算有两种：
  - 语言内置的计算：非常底层的类型，如加法、减法、乘法等。
  - 程序员自己定义的计算：把已有的原始计算类型组合起来，创建新的计算类型，计算机也能执行这些新计算。
- 讲者强调要反复记住：**计算机只知道你告诉它的东西，只做你让它做的事。它们不是魔法，没有思想，只是计算速度非常快，但必须由你告诉它要算什么。**

### 5. 声明式知识与命令式知识

讲者区分了两种知识类型：

- **声明式知识**：事实陈述。
  - 事实陈述示例：今天课前会有人赢得奖品，奖品是 Google Cardboard——讲者称其为“Google 最先进的虚拟现实眼镜”。她确实在课上带来了奖品，兑现了承诺。
- **命令式知识**：配方、方法、或者“怎么做”的步骤序列。

#### 课堂抽奖示例

讲者把自己当作一台机器，按照事先给出的命令式步骤执行：

1. 已经完成：想报名的人已经报名。

4. 在第一个到第 n 个响应者之间随机选一个数。
5. 讲者实际使用 Python 的 `random.randint`，在 16 到 272 之间取随机数。
6. 得到 75。
7. 在响应者名单中找到 75 号，获奖者是 Lauren Z-O-V，她在现场。

讲者说明，这个例子同时展示了：生活中的简单任务也可以用计算机或编程完成；并且自己当机器时完全按步骤走。如果让她自己选随机数，可能会有偏见（例如她可能偏爱数字 8）。讲者还鼓励大家尽可能在日常生活中使用 Python 来练习。

#### 平方根数值示例

- **声明式知识**：`√x` 是满足 `y × y = x` 的 `y`。这只是一个事实陈述，计算机不知道如何用它。
- **命令式知识/算法**，以 `x = 16`、初始猜测 `g = 3` 为例：
  1. 计算 `g × g`，得到 9。
  2. 判断 `g × g` 是否足够接近 `x`。如果足够接近，就停止，并说 `g` 是答案。
  3. 如果不够接近，就生成一个新猜测：`(g + x/g) / 2`。
  4. 用新猜测重复上述过程。
- 该算法会不断重复，直到你认为足够接近为止。

#### 配方/算法的三个部分

讲者从上面的算法中总结：

- **简单步骤序列**：例如上例中有四步。
- **控制流**：有些地方要做决定（“是否足够接近？”），还有些地方要重复步骤（“重复步骤 1、2、3”）。
- **停止条件**：不能让程序或配方永远运行下去。例如不要把面包永远烤下去，10 个面包就够。上例中的停止条件是“判断足够接近”，比如误差在 0.01、0.001 之内，数值由你选择。

讲者指出，在计算机科学中，这样的配方就是**算法**，也是本课程要学的内容。

### 6. 固定程序计算机与存储程序计算机

讲者从历史角度解释两类计算机：

- **固定程序计算机**：
  - 例子：老式计算器，只能做数字的加、减、乘、除。
  - 它只知道这一件事：算算术。不能绘图、不能上网、不能发邮件。
  - 如果想要一个能完成其他任务的机器，就必须另造一台完全不同的固定程序计算机。
  - 讲者说自己年龄大到用过这种设备。
- **存储程序计算机**：
  - 这种机器能存储一系列指令，并能执行这些指令。
  - 你可以更改指令序列，然后执行不同的任务。
  - 这就是我们今天所认识的计算机。

#### 基本机器架构

讲者介绍了每台计算机核心的基本架构，包括四个主要部分：

- **内存**：存放数据和指令序列。
- **输入与输出**。
- **ALU（算术逻辑单元）**：执行所有操作的地方；ALU 能做的操作非常原始，比如加法、减法等。
- **控制单元**：与 ALU 交互，内部有一个程序计数器。

工作流程：

1. 加载一系列指令后，程序计数器从第一条指令开始。
2. 它获取当前指令，并发送给 ALU。
3. ALU 可能会从内存取数据，例如要加两个数，就从内存取两个数；也可能执行操作并把数据存回内存。
4. ALU 完成后，程序计数器加 1，进入指令序列的下一条。
5. 通常按指令线性逐条执行。
6. 某些指令可能是测试，例如判断“某个值是否大于、等于或小于另一个值”。测试返回 `true` 或 `false`。根据结果，程序可能进入下一条指令，也可能把程序计数器设置回开头，从而产生控制流。因此不总是线性执行，可能跳过指令或从头开始。
7. 执行完最后一条指令后，可能输出某些内容。

讲者总结：存储程序计算机包含指令序列；它能执行的原始操作包括加法、减法、逻辑运算、测试（等于、小于等）以及移动数据（存储数据、移动数据等）；解释器逐条检查指令，并决定是进入下一条、跳过指令、还是重复指令等。

### 7. 图灵六原语与重要推论

- Alan Turing 证明：使用六个原语就可以计算任何东西。
- 六个原语是：**左移、右移、读、写、扫描、什么都不做**。
- 使用这六条指令和一条纸带，Turing 证明可以计算任何东西。
- 编程语言在这些六条指令之上创建了更方便的原语集合，你不需要只用这六条命令编程。
- 一个非常重要且有力的推论：**如果你能用 Python 写程序计算某件事，那么理论上你也可以用任何其他语言写程序计算完全相同的事情。** 讲者强调这是非常强大的陈述，建议大家课后复习幻灯片时再想一想。

### 8. 语法、静态语义与语义

讲者用英语和编程语言做类比。

#### 原语构造

- 英语的原语构造是单词，数量很多。
- Python 也有原语，但数量没有英语单词那么多，例如浮点数、布尔、数字、字符串，以及加法、减法等简单运算符。

#### 从原语构造表达式

- 在英语中，组合词可以形成短语、句子。
- 英语例子：
  - `cat, dog, boy` 是“名词、名词、名词”，**句法无效**。
  - `cat, hugs, boy` 是“名词、动词、名词”，**句法有效**。
- Python 例子：
  - 类似“一个单词然后数字 5”的组合句法无效。
  - 类似“运算符、操作数、运算符”的组合是有效的。

#### 静态语义

- 英语例子：
  - `I are hungry` 句法正确，但说法很怪；代词、动词、形容词的组合不太对。
  - `I am hungry` 更好。
  - 前者静态语义不好。
- Python 例子：
  - `3.2 * 5` 没问题。
  - 但“一个单词加上一个数字”没有意义：句法上运算符-操作数-运算符是对的，但把数字加到单词上不合理。

#### 语义

- 英语中，一个句子可能有不止一种含义。例如：
  - `Flying planes can be dangerous` 可以有两种含义：驾驶飞机这件事很危险，或者飞行中的飞机很危险。
  - 双关例子：`This reading lamp hasn't uttered a word since I bought it. What's going on?`
- 但在编程语言中，你写的程序、指令序列**只有一种含义**。程序不会突然决定添加一个变量，它只会执行你写的语句。
- 问题在于：程序的含义可能不是程序员原本想要的。这就是后面会讲到的调试主题。

#### 三类错误

- **语法错误**：
  - 讲者在现场输入了一个语法错误的例子，Python 显示“愤怒的文本”，指出出错行并提示该行语法不正确，程序员可以回去修复。
  - Python 很容易捕捉语法错误。
- **静态语义错误**：
  - Python 也能捕捉，但前提是程序运行到了发生静态语义错误的分支。
- **语义错误/不同含义**：
  - 这可能是初学者最沮丧的一类错误。
  - 程序可能会给出与预期不同的输出：例如你期望某个测试用例输出 0，实际却输出 10。这不是程序突然决定改成 10，而是它执行了你写的程序。
  - 程序可能崩溃，也就是停止运行，这也没关系，回去检查代码即可。
  - 程序也可能不停运行，这也没关系，有办法停止它，不必重启电脑。

### 9. Python 程序的结构

- Python 程序是**定义和命令**的序列。
- 有表达式会被求值，也有命令告诉解释器做某些事。
- 如果你做过 problem set 0，就会知道：
  - 可以直接在 shell 中（右侧）输入命令，例如 `2 + 4`。
  - 也可以在左侧编辑器中输入多行更复杂的程序，然后运行。
- 通常，右侧 shell 用于测试非常简单的内容；左侧编辑器用于写更多行、更复杂的程序。

### 10. Python 对象与标量类型

- 讲者再次强调：在 Python 中**一切皆对象**，程序操作这些数据对象。
- 所有 Python 对象都有类型。类型告诉 Python 可以对这个对象执行哪些操作。
- 例子：
  - 对象是数字 5 时，可以把它加到另一个数字上、减去另一个数字、求幂等。
  - 更一般的例子：讲者是 human 类型，可以走路、说英语等；Chewbacca 是 Wookie 类型，可以走路、发出讲者无法发出的声音，但讲者做不到。
- 对象分两类：
  - **标量对象**：非常基本的对象，不可再分。例如数字 5。
  - **非标量对象**：有内部结构，可以被细分。例如列表 `[5, 6, 7, 8]`，它由一串数字组成。
- Python 中的标量对象有：
  - **整数**：所有整数。
  - **浮点数**：所有实数，带小数点的数。
  - **布尔**：只有两个值 `True` 和 `False`，注意首字母大写（大写 T 和 F）。
  - **NoneType**：很特殊，只有一个值 `None`，表示“没有类型”。它在某些程序中会有用。
- 查看对象类型：使用 `type()`，例如 `type(5)` 会告诉你是整数。

#### 类型转换

- Python 允许在不同类型之间转换。
- 做法：把目标类型名放在要转换的对象前面。
- 例子：`float(3)` 会把整数 3 转换为浮点数 3.0。
- 浮点数转换为整数时会**截断**：去掉小数点和后面所有内容，只保留整数部分；**不会四舍五入**。

### 11. 打印与交互

- 打印是用户交互的方式，使用 `print` 命令。
- 在 shell 中，直接输入 `3 + 2` 确实会显示一个值 `5`，但这并不是真正的打印。
- 如果在编辑器中只写 `3 + 2` 并运行程序，右侧不会实际打印任何东西。
- 在控制台直接输入表达式显示值，这只是给程序员自己“偷看”值，并不是打印给其他人。
- 要真正打印，必须使用 `print` 语句，这样才会把数字 `5` 输出到控制台。
- 从显示上看：
  - 带有 `Out` 的输出表示是 shell 中的交互，不是打印。
  - 如果没有 `Out`，就说明内容被打印到了控制台。

### 12. 表达式与运算符

- 对象与运算符组合形成表达式。
- 每个表达式有一个值，表达式求值得到一个值。
- 基本语法：**object operator object**。
- 整数和浮点数上的常见运算符：`+`、`-`、`*`、`/`。
  - 对于 `+`、`-`、`*`，结果类型取决于操作数的类型：
    - 两个操作数都是整数，则结果是整数。
    - 至少有一个操作数是浮点数，则结果是浮点数。
  - 除法 `/` 特殊：**无论操作数是什么类型，结果总是浮点数**。
- 其他有用运算：
  - 取余数：使用 `%`。`i % j` 给出 `i` 除以 `j` 的余数。
  - 求幂：使用 `**`。`i ** j` 给出 `i` 的 `j` 次方。
- 运算优先级与数学中的典型优先级一致。可以用括号改变优先级。

### 13. 变量与赋值

- 将值保存到一个名字很有用。名字应由程序员选择，最好有描述性。
- 保存值到名字后，可以在程序后面访问该值。
- 赋值使用等号 `=`。
- 赋值把右侧的值赋给左侧的变量名。
- 例子：
  - `pi = 3.14159` 把浮点数 3.14159 赋给变量 `pi`。
  - `pi_approx = 22 / 7` 先求值表达式，得到某个小数，然后保存到变量 `pi_approx`。
- 值存储在内存中。Python 中的赋值将名字**绑定**到值。
- 以后在程序中使用该名字时，就引用内存中的值。
- 给表达式命名的好处：
  - 可以重用名字，而不是值。
  - 代码更清晰。
- 圆面积代码示例：
  - `pi = 3.14159`
  - `radius = 2.2`
  - `area = pi * radius ** 2`
  - 最后一行先查找内存中 `pi` 和 `radius` 的值，替换到表达式中，再做计算，整个表达式被一个浮点数结果替换，并赋给 `area`。

#### 编程与数学的区别

- 数学中常见的问题是“解出 x”，例如 `x + y = ...`，要求解 x。
- 计算机不知道如何解这样的式子。计算机必须被明确告知怎么做。
- 在编程中，如果想解 x，你必须告诉计算机如何解 x，也就是给出公式。
- 因此，在编程中：
  - **右侧总是一个表达式**，会被求值为一个值。
  - **左侧总是一个变量**，用于赋值。
  - 等号不同于数学中的等号：左侧只能有一个变量。
  - 等号表示**赋值**。

### 14. 重绑定变量与内存行为

讲者通过内存示意图解释变量重绑定：

- 初始：
  - `pi = 3.14`：在内存中创建值 3.14，绑定到名字 `pi`。
  - `radius = 2.2`：在内存中创建值 2.2，绑定到名字 `radius`。
  - `area = pi * radius ** 2`：从内存取出 `pi` 和 `radius` 的值，计算表达式，把结果放入内存，并赋给变量 `area`。
- 然后执行：
  - `radius = radius + 1`
  - 这会先解除 `radius` 与 2.2 的绑定。
  - 计算 `radius + 1` 得到新值 3.2。
  - 将 `radius` 重新绑定到 3.2。
- 注意内存中仍然存在 2.2 这个值，但已经失去了指向它的“句柄”，无法再取回。它只是留在内存里，可能在某个时候被 Python 的垃圾回收器收集并重用。
- `radius` 现在指向新值 3.2，无法再得到 2.2。
- **非常重要的结论**：`area` 的值没有改变。
  - 原因：我们没有告诉计算机重新计算 `area`。
  - 我们只告诉计算机把 `radius` 改为 `radius + 1`。
  - 如果程序员把计算 `area` 的那一行复制到 `radius = radius + 1` 之后，`area` 才会改变。
  - 这再次印证：计算机只做你告诉它做的事。

## 关键结论与强调

- 计算机只执行你写出的指令，不会自行决定，也没有“魔法”。
- 声明式知识是事实，命令式知识是可以执行和重复的步骤序列。
- 算法需要步骤序列、控制流和停止条件。
- 存储程序计算机通过解释器逐条决定执行路径，从而实现不同任务。
- 图灵六原语说明理论上不同编程语言的计算能力等价。
- Python 程序只有一种含义，但错误可能来自语法、静态语义或与预期不同的语义。
- Python 中一切皆对象，标量对象包括整数、浮点数、布尔和 NoneType；类型转换会截断。
- 打印必须使用 `print`，shell 显示的值只是给程序员临时查看。
- 表达式的值依赖运算符和操作数类型，除法总是得到浮点数。
- 赋值是名字到值的绑定，重绑定只会改变指定变量，不会自动更新依赖它的其他变量。
