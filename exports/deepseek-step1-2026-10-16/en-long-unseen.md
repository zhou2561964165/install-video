## 高层概览

本节课在上一讲“计算机只按指令执行”的基础上，引入程序控制流。主要内容包括：字符串类型及拼接、重复操作；print 输出与逗号/加号的差异；input 用户输入及其字符串特性；比较运算符和逻辑运算符；分支结构 if / elif / else；while 循环；for 循环与 range；break；以及 for 与 while 的使用选择。核心前提不变：计算机不会自发做决定，程序员通过条件和循环把决策与重复行为构建进程序。

## 详细要点

### 1. 上节回顾与本节目标

- 上次课的要点：计算机只做被要求做的事，不会自行决策。
- 已学对象类型：整数 int、浮点数 float、布尔值 bool。
- 本节新增：字符串 string、分支和循环。

### 2. 字符串 string

- 字符串是字符序列，字符可以是字母、数字、特殊字符和空格。
- Python 中用引号括起来表示字符串；单引号或双引号均可，只要前后一致。
- 示例：`hi = "hello there"` 将字符串对象绑定到变量 `hi`。
- 字符串操作一：拼接 concatenation。使用 `+` 把两个字符串连在一起，但 `+` 不会自动添加空格。
  - 示例：`hi = "hello there"`，`name = "ana"`，`hi + name` 得到 `"hello thereana"`，没有空格。
  - 如果需要空格，必须手动插入：`hi + " " + name` 才得到正确问候。
- 字符串操作二：用 `*` 重复字符串。`字符串 * 数字` 表示把该字符串重复指定次数。
  - 示例：用括号先拼接空格与名字，再乘以 3；结果会先把空格与名字重复三次，再与 `"hello there"` 拼在一起。
  - 括号用来明确运算顺序：先执行括号内拼接，再执行乘以 3。

### 3. print 输出细节

- `print(...)` 用于与用户交互，在括号中放要显示的内容。
- 在 print 中使用逗号：Python 会自动在逗号分隔的两个值之间加一个空格；逗号分隔的对象不必都是字符串，这是优点；缺点是会产生额外空格。
- 在 print 中使用 `+`：Python 不会自动加空格，只按你写的内容拼接；但所有对象都必须是字符串，数字需要先转换成字符串。
- 示例：三个 print 的对比。
  - 全用逗号时，每个对象之间都有空格；
  - 逗号与拼接混合时，只在逗号处出现额外空格；
  - 全用拼接时，不会额外添加空格。
- 数值转字符串示例：`x = 1`，可用 `str(1)` 等把数字转成字符串后参与拼接。

### 4. input 用户输入

- 使用 `input("提示文本")` 获取用户输入。
- 程序会显示提示文本并停止，等待用户输入并按下回车。
- 重要规则：无论用户输入什么，`input` 总是把输入内容作为字符串返回。
  - 示例：用户输入 `"ha"`，`print(5 * text)` 输出 `"hahahahaha"`；
  - 用户输入数字 `5`，若不转换，`5 * text` 会输出 `"55555"`，不是 25。
- 若要按数字处理，必须显式转型：`int(input(...))` 或 `float(input(...))`。
  - 示例：输入 5，转为 int 后 `5 * 5` 得到 25。
- 听众问：为什么需要把字符串转成数字？讲者解释：`input` 默认总是产生字符串；如果要按数字运算，必须显式告诉 Python 使用数字类型。

### 5. 比较运算符

- 对变量 `i` 和 `j` 进行比较会产生布尔值：True 或 False，用作条件测试。
- 允许比较：int 与 int、float 与 float、string 与 string、int 与 float。
- 不允许比较：string 与 number。尝试 `'a' > 5` 会报错，Python 无法理解如何比较字符串和数字。
- 运算符：`>`、`>=`、`<`、`<=`、`==`、`!=`。
- 单等号 `=` 是赋值；双等号 `==` 是相等测试。
  - `i == j`：变量 `i` 的值是否等于变量 `j` 的值；
  - `i != j`：变量 `i` 的值是否不等于变量 `j` 的值。
- 字符串之间的 `>`、`<` 按字典序/字母顺序比较。示例：`'a' > 'b'` 为 False，因为 b 在字母表中更靠后。

### 6. 布尔逻辑运算符

- `not a`：对布尔值 `a` 取反；`a` 为真则 `not a` 为假，反之亦然。
- `a and b`：仅当 `a` 和 `b` 都为 True 时结果才为 True。
- `a or b`：仅当 `a` 和 `b` 都为 False 时结果才为 False。
- 这些逻辑运算符用于组合测试条件。

### 7. 分支：if、elif、else

- 引入示例：MIT 迷宫找免费食物。
  - 算法：始终让右手扶着墙走。
  - 步骤为：
    1. 如果右边没有墙，向右走直到碰到墙；
    2. 否则如果右边有墙且前方可走，继续前进；
    3. 如果右边和前方都有墙，向左转；
    4. 如果右边、前方和左边都有墙，转身往回走。
  - 这个自然语言算法包含“如果”“否则”等表达，编程中也有对应构造。
- 讲者观点：计算机本身不会自己做决定；程序员把决策点写进程序，计算机只是到达决策点后选择一条路径。
- 三种基本控制流：
  - 简单 `if`：到达 if 时检查条件；条件为 True 才执行缩进代码块中的额外语句；条件为 False 则跳过该代码块，继续后续程序。
  - `if-else`：二选一。条件为 True 执行 if 块；否则执行 else 块。只执行其中一个，随后继续主程序。
  - `if-elif-else`：多于两个选择。`elif` 是 `else if` 的简写，可以有多个；最后的 `else` 是兜底，即前面所有条件都不为 True 时执行。
- 多分支规则：如果多个条件都为 True，只进入第一个为 True 的代码块，不会进入多个代码块。
- 代码块由缩进表示，通常为四个空格；Python 的缩进使控制流更直观。
- 条件可以嵌套：内层 if 只有进入外层 if 后才会被检查。
- 常见错误：在 if 中使用单等号进行赋值会导致语法错误。检查相等应使用双等号 `==`。Python 会给出语法错误并高亮相应行。

### 8. while 循环

- 动机：用当前知识编码 Zelda 迷失森林游戏会遇到问题。
  - 规则：如果用户一直选择 right，就反复显示森林画面；选择 left 才退出。
  - 若只使用嵌套 if，不知道用户会输入多少次 right，嵌套可能无限深；因此需要循环。
- 用 while 改写：
  - `while user exits right:` 后缩进 `set background to woods background`。
  - 条件为 True 时执行缩进代码块，然后回到顶部再次检查条件；条件仍为 True 就继续循环，条件变为 False 时退出循环并执行 while 之后的代码。
- 讲者展示的文字版 Zelda 森林示例：
  - 程序输出 `"You're in the Lost Forest. Go left or right."`；
  - 获取用户输入；
  - 如果用户一直输入 right，就继续显示同样提示并再次询问；
  - 输入 left 则退出循环，输出 `"You've got out of the Lost Forest."`。
- 讲者额外改进与练习建议：
  - 讲者展示了一个更复杂的版本：如果用户一直向右，程序会显示砍树、建桌子、掀桌等。
  - 评论中建议：使用计数器；前两次输入 right 只显示 sad face，超过两次再触发砍树、建桌、翻桌，作为循环练习。
- 用 while 计数：
  - 必须先在循环前初始化计数器变量；
  - 必须在循环体内递增计数器；
  - 否则可能陷入无限循环。
  - 示例：`while n < 5: print(0)` 如果没有递增 `n`，会无限打印 0。
- 无限循环处理：
  - 讲者演示了 `while True: print(0)` 导致无限输出；
  - 在控制台按 Control-C 或 Command-C 可以停止程序，避免拖慢电脑；
  - 讲者观点：遇到无限循环不是世界末日。

### 9. for 循环与 range

- 前面的 while 计数示例可以改写为：
  - `for n in range(5): print(n)`。
- 内部机制：
  - `range(5)` 生成序列 0、1、2、3、4；
  - 循环变量 `n` 依次取序列中的每个值，每次执行缩进代码块；
  - 序列结束后退出循环。
- for 循环结构：
  - `for 循环变量 in range(...):` 后跟缩进代码块。
- range 定制：
  - `range(stop)`：默认 start=0，step=1；
  - `range(start, stop)`：给定 start 和 stop，step 默认为 1；
  - `range(start, stop, step)`：给定 start、stop 和 step。
  - 序列总是从 start 开始，到 stop-1 结束，不包含 stop。
- 示例 1：`sum = 0`，`for i in range(7,10): sum += i`。
  - `i` 依次为 7、8、9；最终 sum 为 7 + 8 + 9 = 24；不会处理 10。
- 示例 2：`range(5,11,2)`。
  - 从 5 开始，步长为 2，依次为 5、7、9；不包含 11。
- 听众问 range 参数是否必须为整数。讲者现场测试后表示：必须是整数。

### 10. break

- `break` 用来提前退出当前所在的最内层循环。
- 遇到 break 时，Python 立即离开最内层循环；该循环中 break 之后的表达式不会执行。
- 在讲座的嵌套 while 示意中：进入内层 while 后执行一个表达式，遇到 break；内层循环同块的后续表达式不会执行；退出内层循环后，继续执行外层 while 中与它同级的后续表达式。
- break 同时适用于 for 和 while。

### 11. for 与 while 的对比（讲者总结）

- for 循环通常用于已知迭代次数的情况。
- while 循环适用于迭代次数不可预知的情况，例如用户输入。
- 两者都可以用 break 提前退出。
- for 循环内建计数器；while 循环可以使用计数器，但必须先在循环前初始化，并在循环内手动递增，否则可能产生无限循环。
- for 循环示例可以改写为 while 循环；但反过来不一定成立。一个反例是用户输入：不知道用户会执行多少次任务，因此很难用 for 替代 while。
