# 小圈取消内容列边界与避让范围调整

日期：2026-10-17。用户明确“两边的限制框”指小圈离开中间内容列后消失的左右边界，不是模型拖动边界；小圈只在顶部组件、模型可见轮廓和中间解析组件处隐藏。

工程约定：沿ui-ux-pro-max/design-system、现有三层token与表现窄接口实施，不改模型/下载/认证状态，不新增依赖。保护本机模型、env/账号、数据库和closed原件；真实LLM POST0，未提交/推送/部署。F-006登录入口仍仅后续事项。

## 改动

只改PointerFollower与EntryScene：去除“必须命中data-ui-follow内容区才显示小圈”的条件，小圈可在两侧空白与其他页面区域显示。用户补充标题角度也应跟随小圈后，按指针所在纵向区间选择标题，横向以全视口位置连续归一化，左右空白区域也能改变倾角；离开纵向区间则清理旧标题变量。避让名单从全部button/input/link/dialog等缩小为`.site-header`、显式`data-follow-exclude="parse"`解析表单及模型alpha轮廓。

解析表单使用DOM标记而非根据任意input/button猜测；普通示例按钮、链接、菜单不再让小圈自动消失。顶部与解析表单沿原范围/余量判定，模型继续使用可见alpha轮廓，无矩形提前隐藏。触屏/窄屏能力、blur、拖动时原生指针等生命周期保护维持原逻辑。

模型代码、拖动边界、手动拖动与松手停留位置、原待机更新均未修改。
