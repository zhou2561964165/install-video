## 当前实现

- `summary_normalization.py`：完整段落/字符串数组/对象数组/编号点先转成内部 DTO；正文和引用提示保持，限值来自配置。完整外层 JSON fence 可本地处理，提取对象中只识别精确的 `type: "json_object"` 无内容格式标记，其余字段由严格 codec 校验。
- `summary_references.py`：程序根据已验证事实、词项与主题提供可追踪关联，不盲挂全部 ID。双方对应子句检查数字和否定，避免把同一复合事实中另一处否定错误套到肯定子句。原文不拆改，歧义/未决显式保留；关联是建议，不证明蕴含。
- `summary_retry.py`：格式与语义分类，实例预算分别计数，默认各 1 次且共享最多 2 次，可配置关闭。来源、网络、供应商、容量和配置错误停止，不重跑整个流水线。
- `llm_service.py`：唯一 HTTP 编排层；先规范化和程序引用，再执行来源、核心覆盖、逐项核查及最终长度约束。没有自动补 true 或发布未决最终引用。

优化模式下预算计数不会依赖 assert；已用真实失败的 `python -O` 测试验证修复。提取 marker、否定作用域两个后续故障均用原始响应及最小案例先红后绿，旧失败及冻结副本保持。
