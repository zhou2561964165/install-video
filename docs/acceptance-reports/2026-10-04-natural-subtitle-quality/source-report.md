# 真实中英文字幕的独立采集与事实冻结

## 工程约定

UI、视觉与交互变更先使用 `ui-ux-pro-max` 和 `design-system`；skill 指引优先于计划；颜色、字体和时长走 primitive → semantic → component token；新增能力可配置、模块通过窄接口单向依赖；只有 `ytdlp_service.py` 接触 yt-dlp；视觉层只读 scene，不改变下载状态。本轮采集脚本只请求官方公开字幕，不修改产品代码、环境文件、ACL 或 cookies，也不调用模型。

## 来源与许可

已获取三份 MIT OCW 官方自然字幕：[manifest.json](corpus/manifest.json)、[原始采集记录](corpus/acquisition.json)。每份字幕来自一个完整独立视频，没有拼接造长、机器翻译或人工扩写。

| 样本 | 语言与自然长度 | 内容 | 获取结果 |
| --- | --- | --- | --- |
| zh-short | 原生中文，608 字符 / 21 行 | 全中文课堂教学条件和英文提问时间 | 官方页面 200、字幕 200 |
| en-medium | 英文，2,199 字符 / 95 行 | 日常评价与私密书面反馈 | 官方页面 200、字幕 200 |
| en-long | 英文，34,894 字符 / 1,516 行 | 单堂计算与 Python 入门课，末尾变量重绑定示例 | 官方页面 200、字幕 200 |

长度使用清洗后 UTF-8 文本的 Python 字符数，不是词数或模型 token；模型服务可能再去重，实际送入长度由模型评测记录另列。短/中/长是本轮相对类别，长文超过默认 20,000 字符的分段阈值；没有六种语言×长度组合或中文长文覆盖。

三份资源的官方页面都标注 CC BY-NC-SA 4.0，并由官方页面引用/嵌入相应 VTT。署名与再用要求见 [语料许可](corpus/LICENSE.md)。[MIT 官方政策](https://ocw.mit.edu/pages/privacy-and-terms-of-use/)同时含有 “Permitted Use of AI Training” 节，允许依适用许可开发、改进 AI 并保留非商业等条件；本轮只做非商业推理评测，没有模型训练。政策返回 200，采集时间及原始页面 SHA-256 见 [license-evidence.json](corpus/license-evidence.json)。

TED 被排除：[其当前官方条款](https://www.ted.com/about/our-organization/our-policies-terms/ted-com-terms-of-use)对未单独授权的 AI 评测、分析、数据集使用有限制；没有仅依旧 CC 字样采集 TED 字幕。没有抓取 TED 内容作为语料。

## 独立预先冻结

独立采集 agent 在没有读取任何本轮模型输出、没有模型调用的条件下，为三份字幕逐项预先标注 **4 / 4 / 6 条必需教学主事实**；长文另列 5 条“出现则校验”的数值或例子。每条都有原文本行号及字符区间，可逐字回查。第一次冻结时刻和独立性声明保存在 manifest；模型评测方须保留整个 manifest 的 hash。这里及 manifest 中的逐项整理指 agent 依据原文核查，并非独立人类评分。

必需事实关注完整含义，而不是强制出现关键词：中文保留第二天开始全中文、固定课堂用语、备课与课堂任务一致、前 45 分钟/末 5 分钟的条件；英文中篇保留每节评价、语言与文化反馈、Engrade 私密评论和按课堂材料给反馈。讲者的文化举例属于本课说法，不认作人人适用的文化真理，也不认作 Engrade 在 2026 年仍可用的推荐。

长篇主事实覆盖计算与存储、事实/步骤知识与停止条件、可变指令和控制流、语法及意图错误、带类型的对象、变量绑定和**尾部 area 不随 radius 重绑定自动重算**。具体 radius 2.2→3.2、int 截断、除法 float 等属于出现则核实的细节，合理省略不作为主事实覆盖失败。行政问候、抽奖范围和宣传不是必需重点。原字幕有口语自我修正、指向投影的表达和教学简化，不以这份字幕证明所有外部计算机知识都正确。

独立审核 agent 依据原文逐项评价时先读主事实、再逐条检查生成内容是否可由字幕支持，再判断两个要点是否只换词重述同一命题；不同条件/例子支持同一教学主旨时不机械地按关键词判重复。这是三个样本的可回查个案评测，不能推出所有字幕的准确率。

## 采集边界与复现

正式采集脚本的四组请求（政策一组、三个页面+字幕组）全部成功，不带认证、不重试；另有先前发现路径探测的资源索引重定向循环及控制系统页面读取超时，未被计入成功字幕，也没有绕过。转用可直接访问的官方课程页面解决来源查找，没有增加产品专用提取器。系统代理只在执行进程设置。

在仓库根目录执行；输出到新目录以保留已冻结证据：

```powershell
& '.venv\Scripts\python.exe' 'docs/acceptance-reports/2026-10-04-natural-subtitle-quality/acquire_corpus.py' --output-dir '.planning/natural-corpus-reacquired'
```

[acquire_corpus.py](acquire_corpus.py)使用有界 HTTP 超时，收到单字幕正文超过 2 MB 时拒绝保留，保留原始字节与 hash；非空输出目录在任何 HTTP 请求前拒绝，已冻结证据不覆盖。[freeze_expectations.py](freeze_expectations.py)把独立采集 agent 预先逐项标注的事实表转换为行号/字符证据，只允许首次写入 manifest；它不读取模型结果。已冻结目录不运行覆盖采集或重新标注，新的评测迭代须另建版本。
